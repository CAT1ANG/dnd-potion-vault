# Алхимический архив

Каталог, печатные QR-бирки и интерактивный инвентарь зелий для настольных ролевых игр.

## [Открыть сайт](https://cat1ang.github.io/dnd-potion-vault/)

Мастер собирает корзину зелий и создаёт печатный лист. Можно распечатать отдельную бирку для каждого флакона или один общий QR-код для всей корзины. Игрок сканирует код, открывает пробку свайпом и наклоняет телефон, чтобы выпить зелье и бросить кубики.

| Зелье | Формула | Диапазон |
| --- | ---: | ---: |
| Обычное | 2к4 + 2 | 4–10 |
| Большое | 4к4 + 4 | 8–20 |
| Отличное | 8к4 + 8 | 16–40 |
| Превосходное | 10к4 + 20 | 30–60 |
| Сопротивление | 1 из 10 видов урона | 1 час |
| Увеличение | 1к4 | 1–4 часа |
| Уменьшение | 1к4 | 1–4 часа |

Зелье сопротивления при выпивании случайно выбирает один из десяти видов урона: звук, излучение, кислоту, некротическую энергию, огонь, психическую энергию, силовое поле, холод, электричество или яд. Игрок получает сопротивление выбранному виду урона на один час.

Зелья увеличения и уменьшения меняют размер выпившего. Бросок `1к4` определяет, сколько часов действует эффект.

## Как устроена версия GitHub Pages

- Сайт полностью статический и работает без собственного сервера или базы данных.
- QR-код содержит только тип зелья или список зелий в наборе.
- QR-коды многоразовые: один код можно сканировать повторно и на разных устройствах.
- Инвентарь хранится в `localStorage` браузера конкретного устройства.
- После выпивания флакон удаляется только из этого локального инвентаря.
- Кнопка QR на карточке создаёт копию зелья для другого игрока, а не переносит единственный экземпляр.

## Сборка

Требуется Node.js 22.13 или новее.

```powershell
npm ci
npm run build:pages
```

Готовый сайт создаётся в папке `docs/`. GitHub Pages должен быть настроен на публикацию ветки `main`, папки `/docs`.

Предыдущая серверная версия сохранена Git-тегом `backup-v24-monolith`.
