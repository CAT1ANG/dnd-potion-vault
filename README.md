# Алхимическая лавка

Одноразовые зелья лечения для настольных ролевых игр. Игрок сканирует QR-код на флаконе, сайт бросает нужное число `к4`, показывает лечение и навсегда гасит конкретную печать. Повторное открытие с любого устройства сообщает, что зелье уже использовано.

## [Открыть лавку](https://potion-vault-dnd-141126.opensky137.chatgpt.site)

| Зелье | Формула | Диапазон |
| --- | ---: | ---: |
| Обычное | 2к4 + 2 | 4–10 |
| Большое | 4к4 + 4 | 8–20 |
| Отличное | 8к4 + 8 | 16–40 |
| Превосходное | 10к4 + 20 | 30–60 |

В проекте также есть четыре постоянные печати мастера: они позволяют проверять интерфейс и делать новые броски без расходования игровых зелий.

## Как это устроено

- Vinext/React отвечает за пергаментный интерфейс и стеклянные флаконы.
- Cloudflare Worker проверяет пароль из QR и бросает кубики через Web Crypto.
- D1 атомарно сохраняет использованные печати, поэтому два одновременных сканирования не могут использовать одно зелье дважды.
- В репозитории хранятся только SHA-256-отпечатки паролей. Исходные пароли, QR-коды и печатные листы находятся в локальной папке `outputs/`, исключённой из Git.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```powershell
npm ci
npm run dev
```

Сборка production-версии:

```powershell
npm run build
```

Для локальной проверки D1 сначала соберите проект, затем примените миграцию:

```powershell
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_spotty_hammerhead.sql
npm start
```

## Почему сайт не размещён на GitHub Pages

GitHub Pages раздаёт только статические файлы. Одноразовые QR требуют серверной атомарной проверки и общей базы между телефонами, поэтому рабочая версия размещена на Cloudflare/Sites. GitHub используется для открытого исходного кода и истории изменений.

Секретные файлы из `outputs/` нельзя добавлять в публичный репозиторий: они содержат исходные ссылки игровых и мастерских QR.
